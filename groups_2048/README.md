# 위수 2048 군: 독립 검증

위수 2048인 군의 정확한 개수는 **아직 알려지지 않았다** (미해결 문제).
여기서는 알려진 부분 결과를 별도 구현으로 다시 계산했다.

- `e_n.py`: P_3(G)=1 (지수-2 중심열 길이 ≤ 2)인 위수 2^n 군의 수 e_n을 Burnside 보조정리로 센다.
  GL(d,2)의 켤레류마다 S^2(g)의 모듈 구조를 수치로 구하고 (f(T)^k의 rank 이용),
  Birkhoff 공식으로 불변 부분공간 수를 센다. 실행: `python3 e_n.py 11` (수십 분).
  결과(`out11.txt`): e_11 = 1,774,274,116,992,171 (C_2^11 포함; 정확히 길이 2인 군은 …170).
- `euler.py`: OEIS A000679 (n ≤ 10)와 e_n의 Euler 역변환으로 직접분해 가능한 군의 기여를 센다.
  여기에 직접분해 불가능하고 P_3 ≠ 1인 군 5개 (C_2048, D, Q, SD, M)를 더한다.

    f(2048) ≥ 1,774,274,116,992,171 + 685,676,131 + 5 = 1,774,274,802,668,307
