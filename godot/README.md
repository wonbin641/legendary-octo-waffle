# Yarr! 07 (야르 07) · Godot 4판

브라우저판(`../src`, Three.js)을 Godot 4.7로 옮긴 것입니다. 브라우저판은 지우지 않았고 그대로 배포됩니다. Godot판은 `../godot-web/`(GitHub Pages의 `/godot-web/`)에 올라갑니다.

- 엔진: Godot 4.7, GDScript, Compatibility 렌더러(웹용).
- 충돌과 길 찾기는 Godot의 물리 엔진이 아니라 브라우저판의 코드를 그대로 옮긴 것입니다(`scripts/phys.gd`). 조작 느낌과 적의 움직임이 같아야 하기 때문입니다.
- 지도는 브라우저판과 같은 난수를 같은 순서로 써서 만듭니다(`scripts/world.gd`). 컨테이너, 상자, 가로등이 같은 자리에 섭니다.

## 옮긴 것

- 스테이지 8개를 처음부터 끝까지: 1, 1-1, 1-2, 2, 3, 3-1, 3-2, 4. 그리고 Godot판에만 있는 스테이지 5.
  - 1 컨테이너 부두 · 1-1 헬멧 부두 · 1-2 무장 부두(무기별 적 10종, 내릴 곳 고르기)
  - 2 불타는 마을(좀비, 감염과 중독, 해독약 주사, 거대 좀비)
  - 3 동물 연구소 · 3-2 차례 연구소(우리 10개, 동물 9종, 출혈·공포·뿔에 받힘, 얼룩말 → 기린 → 코끼리 탑승, 거대 고릴라)
  - 3-1 사파리 감시탑(5분 뒤 습격, 탑 체력 10,000)
  - 4 우주선(운전실의 황금꿀벌드론과 메인홀 열쇠·세이브 포인트, 메인홀의 3페이즈 보스 드론, 바닥 붕괴와 해치)
  - 5 장난감 방(Godot판에만 있음): 아이 방 전체가 싸움터. 장난감 100개(플라스틱 군인 30, 액션 피규어 22, 태엽·RC 유닛 24, 조립 블록 피규어 24), 장난감 무기 9종, 나무 상자 24개. 보스는 없습니다.
- 무기 8종, 나무 상자와 회복 물약, 오토바이 헬멧·방탄조끼·제트백팩.
- 컷신 일곱 가지: 헬기로 내려오기와 헬기로 나가기(1, 1-1, 1-2, 2, 3-1), 연구소의 시작(원숭이 박사가 버튼을 누름)과 끝(비상 출입문), 우주선의 시작(에어록 문이 열리고 등 뒤에서 닫힘)과 끝, 우주선 운전실·메인홀 문 앞의 보스 소개. Space, Esc, Enter, E, 클릭, 터치로 건너뛰고, 건너뛰어도 그 뒤 상태는 끝까지 본 것과 같습니다. 연구소 우리의 시계는 버튼을 누른 뒤 플레이가 시작될 때부터 돕니다.
- 작전 지도: 플레이 중 M 키(터치는 지도 버튼), 일시정지의 "지도" 버튼, 브리핑. 지형, 내 위치와 방향, 적의 위치와 종류, 상자, 보스, 연구소 우리의 남은 시간, 감시탑 체력, 우주선 바닥이 무너진 뒤의 구덩이까지 보입니다. 스테이지 5의 지도는 Godot판에서 새로 정한 색과 범례입니다.
- 메인 메뉴(항만 관제 콘솔), 스테이지마다 추천 스펙(적합/부적합), 부적합일 때 상점의 추천 상품.
- 상점(아이템, 무기 대여, 탄약, 상아), 무기 편성, 총기 커스텀, 도감(총 9종과 근접 공격, 8개 스테이지의 적 35종; 첫 클리어 뒤에 열리고, 적 카드는 그 적이 나오는 스테이지를 깨면 열림), 설정, 저장 코드(브라우저판의 코드도 읽습니다. Godot판 코드는 총기 커스텀까지 담습니다)와 메일로 보내 두기(메일 앱, Gmail, 메일 내용 복사; 받는 주소는 이 기기에만 기억).
- PC(마우스·키보드)와 터치 조작. 터치에서는 조준하면 저절로 쏘고, 상자가 닿을 거리에 오면 저절로 근접 공격을 합니다.

## 브라우저판과 다른 것

- 생김새: 적, 동물, 로봇, 건물은 상자 몇 개로 단순하게 그렸습니다(손에 든 총 8종과 부착물은 브라우저판 모양 그대로입니다). 크기, 맞는 부위, 충돌은 브라우저판 값 그대로입니다.
- 스테이지 5에는 컷신이 없습니다(낙하산으로 내려오며 시작하고, 깨면 바로 결과가 나옵니다). 보스 소개에서 황금꿀벌드론의 날개가 따로 움직이지 않습니다(생김새를 맞출 때 함께 고칩니다).
- 맞은 적이 번쩍이는 효과, 먼 적을 단순하게 그리는 처리가 없습니다.
- 터치 화면의 일시정지 버튼과 지도 버튼이 오른쪽 위에 위아래로 있습니다(브라우저판은 일시정지가 왼쪽 위, 지도가 오른쪽 위).
- 소리는 브라우저판의 합성 소리를 미리 파일로 만들어 둔 것입니다(`tools/make_sounds.py` → `sounds/`).
- 모든 스테이지를 처음부터 할 수 있습니다(브라우저판은 앞 스테이지를 깨야 다음 스테이지가 열립니다).
- 스테이지 5는 브라우저판에 없습니다. 깬 기록은 저장 코드에 담기지 않고(저장 코드의 스테이지 자리가 8개뿐입니다), 도감에도 장난감 적은 없습니다(도감은 브라우저판의 것 그대로입니다).
- 안드로이드 앱은 만들지 않았습니다(앱 업데이트 중단). 웹 내보내기만 있습니다.

## 만들기와 시험

```bash
GODOT=/path/to/godot ./tools/build_godot.sh     # build/godot-web, build/godot-artifact, 그리고 ../godot-web(GitHub Pages)
godot --headless --path godot res://tests/run.tscn   # 브라우저판에서 뽑은 기준 자료와 비교
node tests/dump_reference.js                    # 기준 자료(godot/tests/reference_stage1.json)를 브라우저판에서 다시 뽑기
```

시험(280개)은 브라우저판에 있는 8개 스테이지마다 충돌 상자·나무 상자의 위치와 길 찾기 격자, 적·동물·로봇의 자리와 종류를 브라우저판 기준 자료와 비교하고, 같은 키 입력의 이동 결과, 무기 8종의 모든 수치, 방아쇠를 누르고 있을 때 남는 탄 수, 가만히 서 있을 때 체력이 깎이는 속도, 저장 코드가 브라우저판과 같은지, 그리고 상점·편성·추천 스펙·커스텀과 스테이지별 규칙(감염, 출혈, 탑승, 감시탑, 문과 세이브 포인트, 보스 페이즈)을 확인합니다. 스테이지 5는 브라우저판 기준 자료가 없어서 장난감 방의 길(계단, 스프링, 투석기, 줄자, 기차)과 장난감 네 종류의 재주(위장, 이단 점프와 활강, 가속과 들이받기, 배터리 나눔과 스파크, 블록 떨어뜨리기·줍기·벽 쌓기·벽 타기)를 따로 확인합니다.
